# Security and responsible use

## Scope

This repository is an **empirical safety evaluation** toolkit. It includes:

- A fixed **prompt bank** designed to stress-test model refusals and borderline compliance under a documented rubric.
- **Model outputs** captured from commercial APIs as part of those evaluations.
- Scripts to **reproduce figures and statistics** from committed artifacts (no API keys are stored in the repo).

## Intended use

Use this project only for **authorized safety research**, **scoped red teaming**, or **education** in line with your organization’s policies and applicable law. Do **not** use prompts, outputs, or scripts here to harass, defraud, or harm people, or to operationalize wrongdoing.

Committed assistant **responses** are **research records**, not instructions. They may be unsafe, incomplete, or outdated relative to current models; **do not treat them as vetted operational guidance**.

## Reporting security issues

If you believe you have found a **security vulnerability in this repository** (for example, accidentally committed secrets), please report it to the maintainers via a **private** channel (e.g. GitHub Security Advisories for the published repo, or direct contact to the repo owner). Do not open a public issue for undisclosed credential leaks.

## Platform content

Some artifacts are intentionally uncomfortable: they document how models respond to harmful or dual-use requests. Hosts and mirrors should apply their own content policies; researchers should handle downloads and sharing responsibly.
