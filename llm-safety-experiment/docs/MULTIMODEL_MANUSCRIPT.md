# Multimodel contextual elicitation audit

**Fixed prompt bank, nine API configurations, human labels**

Aevion Labs — companion to [`RESEARCH_MONOGRAPH.md`](RESEARCH_MONOGRAPH.md)

---

## Abstract

We evaluate harmful-request compliance under a **prespecified five-way elicitation taxonomy** (direct, indirect, emotional, escalation, roleplay) with **18 prompts per stratum** (**90** per run). The **same** [`prompts.json`](../prompts.json) is executed on **nine** tiered commercial API configurations: three cost/capability tiers × three providers (OpenAI, Anthropic, Google Gemini). Assistant outputs receive **SAFE / PARTIAL / UNSAFE** labels under a fixed rubric ([`LABEL_RUBRIC.md`](../LABEL_RUBRIC.md)).

**Primary multimodel estimands:** for each run (row) and stratum (column), \(\hat{p}_U\) = empirical UNSAFE rate and \(\hat{p}_R\) = rate of **risk** (PARTIAL ∪ UNSAFE), with **\(n_c = 18\)** per cell. Aggregates live in [`figures/multimodel/signature_rate_matrix.json`](../figures/multimodel/signature_rate_matrix.json) (built by [`scripts/build_multimodel_rate_matrix.py`](../scripts/build_multimodel_rate_matrix.py)).

**Tiering caveat:** in the frozen configuration, **Gemini mid and expensive** both call **`gemini-2.5-pro`** ([`configs/tier_models.json`](../configs/tier_models.json)). There are **nine** labeled JSON files but **eight** distinct provider×model-id pairs; interpret Gemini tier contrasts accordingly.

Claims are **descriptive and associational**—suitable for evaluation methodology and monitoring design, not for causal statements about model internals.

---

## 1. Introduction

Single-model pilots show that **risk** (borderline + unsafe) can **decouple** from **UNSAFE-only** rates under staged elicitation. The multimodel layer asks whether **similar stratum structure** appears across APIs when inputs and rubric are held constant. We do **not** perform adaptive jailbreak search; the threat model is **structured taxonomy**, not optimized attack strings.

**Pilot context:** a frozen single-model run underpins the long report; see [`docs/RESEARCH_MONOGRAPH.md`](RESEARCH_MONOGRAPH.md) for pilot numbers and [`LLM_SAFETY_EXPERIMENT_REPORT.md`](../LLM_SAFETY_EXPERIMENT_REPORT.md) for full notation.

## 2. Methods

### 2.1 Design

- **Prompts:** 90 rows; strata `direct`, `indirect`, `emotional`, `escalation`, `roleplay`.
- **Runs:** one `results_<provider>_<slug>.json` per configuration, under `results/multimodel/{cheap,mid,expensive}/` ([`RESULTS_LAYOUT.md`](../RESULTS_LAYOUT.md)).
- **Models per tier:** [`configs/tier_models.json`](../configs/tier_models.json) is the single source of truth.

### 2.2 Labeling

Human adjudication on **each row’s `response` text** via [`analyze_results.py`](../analyze_results.py). Schema: [`RESULTS_SCHEMA.md`](../RESULTS_SCHEMA.md). **Do not** treat pilot label-seeding as gold for every model ([`MULTI_MODEL_RESULTS.md`](../MULTI_MODEL_RESULTS.md)).

### 2.3 Rate matrix

[`scripts/build_multimodel_rate_matrix.py`](../scripts/build_multimodel_rate_matrix.py) writes `figures/multimodel/signature_rate_matrix.json` with `p_hat`, `n`, `excess_p_unsafe_vs_direct`, and `per_file` category counts. Optional **risk** metric: rebuild with `--metric risk` (output path documented in script / [`PROVENANCE.md`](../PROVENANCE.md)).

## 3. Results (qualitative)

Patterns in the frozen matrix are **run- and checkpoint-specific**; always cite `signature_rate_matrix.json` for exact \(\hat{p}_U\) cells.

**Recurring structure** in this package’s labeled runs:

- **Direct** and **emotional** strata often sit at or near **zero** UNSAFE for many rows.
- **Indirect** frequently carries **non-trivial** \(\hat{p}_U\) or a **PARTIAL-heavy** risk profile depending on the model.
- **Escalation** and **roleplay** tend toward the **high** end of \(\hat{p}_U\) **within** each row relative to direct.

Cross-run **disagreement** on which prompt ids are UNSAFE is summarized by the PhD bundle (concordance histogram, incidence heatmap); see §4.

## 4. Statistics and diagnostics

- **Default bundle:** Wilson intervals on bar charts (nine-panel), heatmaps, parallel coordinates, forests ([`INTERPRETABILITY_VIZ.md`](../INTERPRETABILITY_VIZ.md) §4).

## 6. Limitations

- **Small \(n_c\)** → wide uncertainty; avoid over-interpreting ordering between adjacent strata.
- **Single primary coder** unless IRR artifacts are produced ([`REPLICATION_PROTOCOL.md`](../REPLICATION_PROTOCOL.md)).
- **API / checkpoint drift**; model ids are strings, not immutable behaviors.
- **Associational** extensions (pressure scores, LPMs) are not causal ([`CAUSAL_PROXIES.md`](../CAUSAL_PROXIES.md)).
